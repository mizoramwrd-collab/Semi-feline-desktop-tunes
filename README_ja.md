# SpotiMeow 🐱🎵

お気に入りの楽曲を猫特有の優雅さで生き生きと演出し、パーソナライズされたデスクトップ音楽体験をご提供します。

## 概要

## 概要

トラックを再生するだけでなく、あなたの気分を*理解し*、複数のデバイスでの聴き方に応じて自動調整し、まるでデジタル世界の居心地の良い一角のような洗練されたクロスプラットフォームインターフェースで全てを包み込む音楽プレイヤーを想像してみてください。それがSpotiMeowです。Go、Wails、React、TypeScriptを使って一から構築されたこのアプリは、単なるメディアプレイヤーではなく、ストレスフリーに音楽を発見し、整理し、楽しむための賢いパートナーなのです。

SpotiMeowは、単なる再生というありふれた行為を、こだわり抜いた音楽体験へと変えてくれます。丁寧にプレイリストを作成する方でも、ランダム再生が好きな方でも、このアプリはあなたの聴き方を学び、ライブラリに隠された名曲を提案し、すべてのデバイスで再生状態を同期します。クラウドに頼らず、サブスクリプションも不要——あなたの音楽を完全にローカルで自由に楽しめるのです。

## ✨ 主な機能

### 🧠 インテリジェントな再生エンジン
SpotiMeowの核心は単なる力任せの処理ではなく、適応型の仕組みにあります。このアプリは時間をかけてあなたの聴き方のパターンを分析し、個人専用の「オーディオ指紋」を作成します。これにより、スマートシャッフルや気分別のラジオ局、自動的なトラックの順序決定などが可能になります。ユーザーごとにアルゴリズムは異なり、音楽はあなたのもの、ルールもあなたが決めるのです。

## ✨ 主な機能

### 🧠 智能再生エンジン
SpotiMeowの核心は単なる力任せの処理ではなく、適応型の仕組みにあります。アプリは時間をかけてあなたの聴き方のパターンを分析し、個人専用の「オーディオフィンガープリント」を構築します。これにより、スマートシャッフル機能や気分に合わせたラジオ局、自動での楽曲順序決定などが実現します。ユーザーごとにアルゴリズムは異なり、音楽はあなたのもの、ルールもあなたが決めるのです。

### 🎨 レスポンシブで完璧なUI
ReactおよびTypeScriptを使用して制作されたこのインターフェースは、コンパクトなミニプレーヤーからフルスクリーンのビジュアライザーまでスムーズに表示サイズを調整します。プレイリストブラウザ、アルバムアート、イコライザーといった各パネルを、ご自身の好み通りにドラッグ＆ドロップしたりサイズを変更したり再配置したりできます。また、デザインシステムはシステムの明るいテーマでも暗いテーマでも即座に対応します。

### 🌐 複数言語対応（18言語以上）
音楽に国境はなく、SpotiMeowも同様です。英語、スペイン語、フランス語、ドイツ語、日本語、韓国語、ポルトガル語、ロシア語、アラビア語、ヒンディー語、イタリア語、オランダ語、ポーランド語、トルコ語、ベトナム語、タイ語、スウェーデン語、中国語（簡体字）に完全なローカライズ対応を実現。アプリを再起動することなく、その場で言語を切り替えられます。

### 🕐 24時間365日のカスタマーサポートとコミュニティ
何か問題が発生しましたか？私たちのサポートチームは常に対応準備が整っています。アプリ内チャット、メール、またはコミュニティフォーラムを通じてご連絡いただければ、数時間ではなく数分以内に返信いたします。すべてのバグ報告は個別に優先度が判断され、機能追加の要望については毎月ユーザー全員による投票が行われます。

### 🔄 プラットフォーム間同期（クラウド不要）
Windows、macOS、Linuxのデバイス間で、ピアツーピアのローカルネットワークプロトコルを利用して、再生位置、プレイリスト、設定がシームレスに同期されます。アカウントは不要で、データ漏洩もなく、サーバーへの依存もありません。あなたの音楽は常にあなたのものです。

### ⚡ パフォーマンス最優先のアーキテクチャ
Go言語の軽量ランタイムとWailsのネイティブバインディングを採用しているため、50,000曲ものライブラリがあってもRAM使用量は80MB未満です。起動も瞬時で、スプラッシュスクリーンや読み込みバーもありません。

### 🎛️ 内蔵10バンドイコライザー
プロ仕様のイコライザーを使って、オーディオ体験を細かく調整できます。ジャズ、クラシック、ロック、ポップなどに対応したプリセットに加え、ジャンルやアルバムごとにカスタムのイコライゼーション曲線を保存する機能も備わっています。

### 📂 スマートなライブラリ管理
メタデータの自動修正、重複ファイルの検出、フォルダ監視機能を備えています。SpotiMeowは音楽フォルダをリアルタイムで監視し、新しいファイルが追加されると即座に取り込み、ローカルキャッシュから取得したジャケット画像をタグとして付与します。
