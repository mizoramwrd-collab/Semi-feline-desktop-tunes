## 概览

想象这样一个音乐播放器：它不仅能播放歌曲，还能*理解*你的情绪，适配你在不同设备上的收听习惯，并通过简洁美观的跨平台界面将这一切呈现出来，仿佛为你打造了数字世界中的舒适角落。这就是 SpotiMeow。它基于 Go、Wails、React 和 TypeScript 从零开始构建，绝非普通的媒体播放器，而是能让你毫无障碍地发现、整理并享受音乐的智能伴侣。

SpotiMeow 将看似平常的播放操作转变成一场精心策划的音乐之旅。无论你是注重整理歌单的精致派，还是喜欢随机播放的爱好者，这款应用都能掌握你的聆听习惯，为你推荐歌库中那些被忽视的佳作，并在所有设备上同步播放状态——无需依赖云端，也无需订阅，让你完全自主掌控自己的音乐。

## ✨ 核心功能

## ✨ 核心功能

### 🧠 智能播放引擎
SpotiMeow 的核心并非简单粗暴的处理方式，而是具备自适应能力的智能系统。该应用会持续分析您的收听习惯，生成专属的“音频指纹”，从而实现智能随机播放、基于情绪的电台功能以及自动曲目排序。每位用户的算法体验都不尽相同——因为这是您的音乐，由您来定规则。

### 🎨 自适应且完美的用户界面
该界面采用 React 和 TypeScript 开发，能够从紧凑的迷你播放器平滑扩展为全屏视觉化界面。您可以自由拖动、调整大小并重新排列播放列表浏览器、专辑封面、均衡器等面板，完全按照您的喜好来布局。其设计系统还支持直接适配浅色与深色系统主题。

### 🌐 多语言支持（18种以上语言）
音乐无国界，SpotiMeow亦然。它完美支持英语、西班牙语、法语、德语、日语、韩语、葡萄牙语、俄语、阿拉伯语、印地语、意大利语、荷兰语、波兰语、土耳其语、越南语、泰语、瑞典语以及简体中文。无需重启应用即可随时切换语言。

### 🕐 全天候客户支持与社区服务
使用过程中遇到问题？我们的支持团队全天候待命。您可以通过应用内聊天、电子邮件或社区论坛与我们联系，我们会在几分钟内而非数小时后给予回复。每份错误报告都会由专人处理，而功能需求则每月由用户群体进行投票决定。

### 🔄 跨平台同步（无需云端）
借助点对点的本地网络协议，您的播放进度、歌单及偏好设置可在 Windows、macOS 和 Linux 设备之间无缝同步。无需账号，无数据泄露风险，也不依赖服务器——您的音乐始终只属于您自己。

### ⚡ 以性能为先的架构
得益于 Go 语言轻量级的运行时以及 Wails 的原生绑定，即便拥有 50,000 首歌曲的曲库，SpotiMeow 的内存占用也低于 80MB。启动速度极快——无需启动画面，也无加载进度条。

### 🎛️ 内置10段均衡器
借助专业级均衡器精心调校您的听觉体验。提供爵士、古典、摇滚、流行等多种预设，同时支持按音乐类型或专辑保存自定义音效曲线。

### 📂 智能音乐库管理
自动修正元数据、检测重复文件，并实现文件夹监控功能。SpotiMeow可实时监测您的音乐目录，即时添加新文件，并使用从本地缓存获取的封面图片为它们添加标签。
